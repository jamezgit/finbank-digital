Projeto 02 • FinBank Digital

Divisão em 2 Grupos & Guia da Infraestrutura

Foco Total do Grupo 01: Cisco Packet Tracer

1. Divisão Formal entre os 2 Grupos

GRUPO 01: Infraestrutura SEU GRUPO

Ferramenta: Cisco Packet Tracer

  • Montagem e cabeamento físico de roteador, switch, servidores e PCs.
  • Criação de VLANs (10, 20 e 30) e link Tronco (802.1Q).
  • Roteamento Router-on-a-Stick e serviços DHCP.
  • Configuração de Web Banking (HTTP), DNS e Syslog.
  • Entrega do arquivo .pkt e da tabela de ativos.
GRUPO 02: Lógica / Software OUTRO GRUPO

Ferramenta: Python 3

  • Implementação dos Requisitos Funcionais (RF01 a RF06).
  • Cadastro de dispositivos e associação aos serviços.
  • Coleta periódica e cálculo de Uptime percentual.
  • Alerta de persistência após 3 falhas consecutivas.
  • Emissão de alertas priorizando ativos críticos.

3. Passo a Passo da Infraestrutura (Cisco Packet Tracer)

Passo 1: Seleção de Equipamentos

1x Roteador 1941 (R-FINBANK), 1x Switch 2960 (SW-FINBANK), 2x Servidores (SRV-WEB-BANCO e SRV-MONITOR), 4x PCs (PC-ATEND-01/02, PC-OPER-01, PC-ADMIN-01).

Passo 2: Cabeamento Porta a Porta (Cabo Direto)

• Roteador G0/0 ➔ Switch G0/1 (Tronco)
• Switch Fa0/1 e Fa0/2 ➔ PCs de Atendimento (VLAN 10)
• Switch Fa0/6 e Fa0/7 ➔ PCs de Operações e Admin (VLAN 20)
• Switch Fa0/11 e Fa0/12 ➔ Servidores Web e Monitor (VLAN 30)

Passo 3: Configuração do Switch 2960

vlan 10
 name ATENDIMENTO
vlan 20
 name OPERACOES_ADMIN
vlan 30
 name SERVIDORES
interface range fa0/1 - 5 ; switchport mode access ; switchport access vlan 10
interface range fa0/6 - 10 ; switchport mode access ; switchport access vlan 20
interface range fa0/11 - 15 ; switchport mode access ; switchport access vlan 30
interface gig0/1 ; switchport mode trunk

Passo 4: Configuração do Roteador 1941 (Router-on-a-Stick)

interface gig0/0
 no shutdown
interface gig0/0.10
 encapsulation dot1Q 10 ; ip address 192.168.10.1 255.255.255.0
interface gig0/0.20
 encapsulation dot1Q 20 ; ip address 192.168.20.1 255.255.255.0
interface gig0/0.30
 encapsulation dot1Q 30 ; ip address 192.168.30.1 255.255.255.0

Passo 5: Testes de Validação

1. Ping entre estações de atendimento e servidores.
2. Acesso Web em http://finbank.local a partir de qualquer PC.
3. Teste de queda de cabo para gerar evento de falha para o Grupo 02.
