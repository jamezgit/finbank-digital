2. Topologia da Rede e Arquitetura Lógica

A arquitetura adota o padrão Router-on-a-Stick, onde um único enlace físico entre o Roteador e o Switch atua em modo Tronco (802.1Q), transportando os pacotes tagueados das VLANs 10, 20 e 30.

+--------------------------+ | R-FINBANK | | Roteador Cisco 1941 | +------------+-------------+ | Gig0/0 | [Enlace Tronco 802.1Q] | Gig0/1 +------------+-------------+ | SW-FINBANK | | Switch Cisco 2960 | +---+----------+---------+-+ | | | +--------------------------+ | +--------------------------+ | Portas Fa0/1 e Fa0/2 | Portas Fa0/6 e Fa0/7 | Portas Fa0/11 e Fa0/12 | | | +-------v------------------+ +----------v---------------+ +----------v---------------+ | SETOR ATENDIMENTO | | OPERAÇÕES & ADMIN | | SERVIDORES INTERNOS | | (VLAN 10) | | (VLAN 20) | | (VLAN 30) | | | | | | | | [PC-ATEND-01] | | [PC-OPER-01] (Caixa) | | [SRV-WEB-BANCO] | | IP: 192.168.10.11 (DHCP) | | IP: 192.168.20.11 (DHCP) | | IP: 192.168.30.10 (Est.) | | | | | | Serviços: HTTP/DNS | | [PC-ATEND-02] | | [PC-ADMIN-01] | | | | IP: 192.168.10.12 (DHCP) | | IP: 192.168.20.12 (DHCP) | | [SRV-MONITOR] | | | | | | IP: 192.168.30.20 (Est.) | | Gateway: 192.168.10.1 | | Gateway: 192.168.20.1 | | Gateway: 192.168.30.1 | +--------------------------+ +--------------------------+ +--------------------------+

4. Configuração Aplicada nos Equipamentos Cisco

4.1 Switch Catalyst 2960 (`SW-FINBANK`)

enable
configure terminal
hostname SW-FINBANK

! 1. Criação das VLANs
vlan 10
 name ATENDIMENTO
exit
vlan 20
 name OPERACOES_ADMIN
exit
vlan 30
 name SERVIDORES
exit

! 2. Portas de Acesso - VLAN 10 (Atendimento)
interface range fastEthernet 0/1 - 5
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
exit

! 3. Portas de Acesso - VLAN 20 (Operações e Administração)
interface range fastEthernet 0/6 - 10
 switchport mode access
 switchport access vlan 20
 spanning-tree portfast
exit

! 4. Portas de Acesso - VLAN 30 (Servidores)
interface range fastEthernet 0/11 - 15
 switchport mode access
 switchport access vlan 30
 spanning-tree portfast
exit

! 5. Configuração do Enlace Tronco para o Roteador
interface gigabitEthernet 0/1
 switchport mode trunk
 switchport trunk allowed vlan all
 description LINK_TRUNK_ROUTER
 no shutdown
exit

end
write memory

4.2 Roteador Cisco 1941 (`R-FINBANK`)

enable
configure terminal
hostname R-FINBANK
service dhcp

! 1. Habilitação da Interface Física Principal (sem IP)
interface gigabitEthernet 0/0
 no shutdown
exit

! 2. Subinterface VLAN 10 (Gateway do Atendimento)
interface gigabitEthernet 0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 description GATEWAY_ATENDIMENTO
exit

! 3. Subinterface VLAN 20 (Gateway de Operações e Administração)
interface gigabitEthernet 0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 description GATEWAY_OPERACOES_ADMIN
exit

! 4. Subinterface VLAN 30 (Gateway dos Servidores)
interface gigabitEthernet 0/0.30
 encapsulation dot1Q 30
 ip address 192.168.30.1 255.255.255.0
 description GATEWAY_SERVIDORES
exit

! 5. Configuração dos Pools de DHCP
ip dhcp excluded-address 192.168.10.1 192.168.10.10
ip dhcp excluded-address 192.168.20.1 192.168.20.10

ip dhcp pool POOL_ATENDIMENTO
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 192.168.30.10
exit

ip dhcp pool POOL_OPERACOES
 network 192.168.20.0 255.255.255.0
 default-router 192.168.20.1
 dns-server 192.168.30.10
exit

end
write memory

6. Relatório de Troubleshooting e Correções Realizadas

Ocorrência 1: Enlace Roteador-Switch Inoperante (Setas Vermelhas)
Causa Identificada: Por padrão de fábrica da Cisco, as portas físicas de roteadores são mantidas em estado administrativo desligado (shutdown).
Ação Corretiva: Execução do comando no shutdown na interface física GigabitEthernet0/0 do roteador e ativação da porta Gig0/1 no switch.
Ocorrência 2: Estações Clientes Recebendo IP 169.254.x.x (APIPA)
Causa Identificada: Conflito de modo de comando na CLI (tentativa de aplicar enable/configure terminal enquanto a sessão já estava no nível de configuração) e ausência temporária do vínculo dot1Q com o pool de DHCP.
Ação Corretiva: Aplicação pontual do bloco de subinterfaces 0/0.10, 0/0.20 e dos pools POOL_ATENDIMENTO e POOL_OPERACOES.
Resultado da Resolução: 100% dos computadores receberam a mensagem DHCP request successful com seus respectivos gateways e servidores DNS associados.
